Leaf feature gallery

Try Leaf’s working features together on one synthetic page. Everything here is an experiment; accepting, rejecting, editing, or reacting does not choose a product direction.

This gallery grows by feature, so a developer can add a focused specimen here without inventing another example page. Start with Leaf’s own controls below, then use the contents spine when it fits beside the page, or open Map. Undo takes back a decision, and a live preview keeps experiments on reload.

          Cancel; an uncertain connection keeps the same attempt pending. The request
          lifecycle above shows the terminal host outcomes, while this board supplies a
          local work seat. Sent, Picked up, and Active describe the handoff to an agent,
          not a second action.
