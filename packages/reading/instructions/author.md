Select this package first on every page, unless the page takes another theme in its
place or carries a design of its own. It is Leaf's reading look: the body's type and
colour, the page's ground, and the face that headings, prose, lists, tables, code
blocks and the page's own buttons and fields read in.

A theme that builds on this one is selected after it and states only what it changes
(`references/package-themes.md`, "A page's theme").
