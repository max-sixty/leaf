A result cache for the search API

The search API's result cache evicts by LRU at 50,000 entries, since memory is the constraint on the search hosts. It serves where the search.cache flag is lru, as it is in staging since 3 November.

What the simulation found

LRU hits 81% of queries and stays under 1.9 GB, but a result can be 41 minutes old at p95. TTL hits 74% and keeps every result under five minutes old, at up to 2.6 GB.

The change

search/cache.py wraps the result lookup in an LRU cache where the search.cache flag is lru.
