Use `lf-visual-review` for a short website journey whose important states can be compared as aligned stills. Put the claim and recommendation in authored prose. The bound `visual-run` supplies the ordered cases, immutable targets, image paths, observed results, and capture conditions.

A page that is only the review is a workspace, `<main class="layout-workspace density-working">`: the review fills the window, and its Fit view sizes each pair to the room the window leaves, so the reader sees a case without scrolling. In a document page, the review is as tall as its evidence and the page scrolls through it. Do not cap a visual object in a page-local scroller.

The widget compares stills. Describe motion that matters in prose; a case's `traceUrl` links a trace when one helps diagnose it.
