Margin entries: every rank, tone, and ownership stage

Everything visible at once. The first row holds every rank, behavior, and tone. The second compares agent ownership: whether the agent has the item. No ownership treatment means not held; pickup uses a green icon; a green interior means working. Ownership decorates the item's existing control. The Activity dot remains only when there is no other control to carry that treatment. These inert specimens use the same constructors and stylesheet as the live controls and status indicators. Reload to see the one-time pulse as Working arrives. A control dims only while its reader action is waiting for the log to confirm it.

Margin entry lifecycle: act, fail, settle, and hand off

Act, fail, and settle. Accept or Reject starts as an action. The content changes immediately, and Undo dims while the event travels.
