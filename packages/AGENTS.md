# Packages

`../skills/leaf/references/packages.md` and the `package-*.md` files beside it own the package
contract, and `../skills/leaf/references/module-authoring.md` and the `module-*.md`
files own what a behavior module must do and the public browser API.
`../skills/leaf/references/interface-principles.md` holds the rules for everything a
widget draws, and `../browser/AGENTS.md` the browser-wide rules for runtime code.
