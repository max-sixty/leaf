Edit the file

Changes save automatically. The editor follows changes made elsewhere and asks which version to keep when edits overlap.

Connect a local file

This example needs a file on the machine serving the page. Bind it explicitly before opening the editor: 

leaf file bind "$PAGE" research-notes /absolute/path/research-notes.md

On a live page, edit a line and inspect the file on disk. A normal save leaves the header still. Hold a write request open to inspect delayed saving feedback; change the file externally during an unsaved edit to inspect conflict recovery. Without a binding, the editor explains what is missing.
