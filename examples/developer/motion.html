Author a motion study

The optional motion package supplies the clock, one play/pause icon, scrubbing and playback speed. The page draws the subject from the supplied time in milliseconds. Scrubbing changes only the view; it writes no decision to the page’s log. 

<lf-motion id="travel" duration="600" aria-label="Travel study">
  <svg viewBox="0 0 300 60" role="img" aria-label="Dot moving right">
    <circle cx="20" cy="30" r="10" fill="currentColor" />
  </svg>
</lf-motion>
import { PAGE_INTERFACE, keeps } from '/runtime/widget-api.js';

const mounted = new WeakSet();
await customElements.whenDefined('lf-motion');
function mount() {
  const study = document.getElementById('travel');
  if (!study || mounted.has(study)) return;
  mounted.add(study);
  const dot = study.querySelector('circle');
  study.renderFrame = (time) => {
    keeps(dot, 'cx', 20 + 260 * time / 600);
  };
}
mount();
document.addEventListener(PAGE_INTERFACE, mount);

Assigning renderFrame draws the current instant immediately. Draw every moving part from that time, so seeking backward and jumping forward produce the same scene as playback. Use currentTime to seek from your own controls.

The studies above preserve the source review’s timing and corrected continuous Leaf travel. Their page module owns those drawings; the reusable widget knows nothing about panels, unread markers or SVG.
