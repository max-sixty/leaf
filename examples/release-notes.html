CLI

Adds --dry-run to every mutating command. Running without it is unchanged, so existing scripts keep working.

API

The v1 header is deprecated, not gone. The note is kept deliberately dry — the Sunset header does the announcing, and the migration guide carries the detail. 

Deprecates the v1 auth header. It keeps working until the next major, and the server now sets a Sunset header on every v1 response.

Console

The run list grew a status column, so a failure now reads off the list instead of costing a click each. It is the release's only visual changeone user-visible layout change. 

Run status now shows on the run list itself. Filtering by it lands in 3.3.
