Agent brief

This large change has a small architectural spine. PreparedDiff owns one complete Git diff invocation, while TempIndex admits untracked files without changing the user’s real index. The picker then decides which rows to warm immediately and which worktree previews to load only when selected.

The historical review found the right failure modes: sparse-checkout divergence, a predictable shared temporary directory, a symlink race while copying the index, and stale claims about prewarming. Those were corrected before merge. Two follow-ups remain visible rather than buried: selected-row demand latency has no benchmark, and wt step commit --dry-run can still stage its own temporary-index artifact when TMPDIR sits inside the worktree.

Three checks for the exact patch

The agent’s review model reduces that architecture to three assertions; each docked line note explains why its assertion matters. 

assert_eq!(real_index_after, real_index_before);
assert!(temp_index.is_operation_scoped());
assert!(offscreen_worktree_preview.is_demand_loaded());
A clean status is insufficient: preview preparation must preserve the real index byte for byte. Random, exclusive temporary files prevent concurrent previews from sharing or replacing one another’s index. Moving off-screen worktrees out of prewarm protects startup, but leaves selected-row latency as a separate measurement question.
Why this is a unified structural diff

Controlled comparison research found that separate layouts help orientation but make correspondence harder as structures diverge. CallDiff keeps unchanged calls as landmarks and puts additions and removals beside them. Leaf adds folding at changed roots so a 31-line capture can remain both compact and inspectable.
