Why test_cache_warmup fails on CI

The cache warmup and the first request race when tests run in parallel, so the test fails in about 1 run in 30 on CI and never on a laptop.

Cause

start() launches the warmup as a background task and returns at once. Under eight parallel workers the first request can arrive before the cache is filled, and misses.

Two fixes

  • Await the warmup in start(): three lines, and startup takes about 200 ms longer.
  • Lock around the cache fill: no startup cost, about forty lines.
