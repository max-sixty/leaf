Review a recorded release journey

This ordinary website has two buttons named Review. Playwright recorded each click; Leaf's comments identify the captured action, image or saved element. Play the captured sequence, or drag the blue handle to scrub and pause on a detail.

Review scenarios
  • Select Page 1 or API calls above the timeline to switch recorded sources. Tab reaches the selected source; arrow keys there change the source. Return to the timeline controls to step through its checkpoints.
  • Select Documentation reviewed or API reviewed on the timeline. Hover or focus each number to read its name and time; close moments stay separate. Zoom in to spread their times and Whole recording to restore the overview.
  • Use Fit image, Actual size, or image zoom to inspect captured pixels. Drag the image to pan, or focus it and use arrow keys. Step through a click’s Before, Action and After checkpoints on one timeline. Each image and saved tree shows its own capture time.
  • Enable Show intermediate frames to include the browser’s filmstrip on that same timeline. Left and Right step through the displayed stops.
  • Comment on one saved Review button, move to another action, and follow the thread back. It returns to that action and tree path.
  • Comment on an image or draw on it. Following the thread restores that exact captured image.
