Review a recorded release journey

This ordinary website has two buttons named Review. Playwright recorded each click; Leaf's comments identify the captured action, image or saved element.

Review scenarios
  • Step through a click’s Before, Action and After checkpoints on one timeline. Each image and saved tree shows its own capture time.
  • Enable Show intermediate frames to include the browser’s filmstrip on that same timeline. Left and Right step through the displayed stops.
  • Comment on one saved Review button, move to another action, and follow the thread back. It returns to that action and tree path.
  • Comment on an image or draw on it. Following the thread restores that exact captured image.
