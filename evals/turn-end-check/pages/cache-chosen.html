A result cache for the search API

The search API caches results with LRU eviction at 50,000 entries, since memory is the constraint on the search hosts.

What the simulation found

LRU hits 81% of queries and stays under 1.9 GB, but a result can be 41 minutes old at p95. TTL hits 74% and keeps results within four minutes, at up to 2.6 GB.

The change

search/cache.py wraps the result lookup in an LRU cache behind the search.cache flag, which is off until it is set to lru.
