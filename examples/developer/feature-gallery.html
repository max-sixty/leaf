lf-button-atlas · Action · Disclosure · Button-shaped status · Lifecycle state · lf-suggestion

Button atlas: every role, tone, and state

Everything visible at once. The first row holds every role and all three behaviors and tones. The second fixes every lifecycle state in place: no mark, dot, moving open ring, diamond, and square. These inert specimens use the same constructor and stylesheet as the live Buttons.

Button workflow: act, fail, settle, and hand off

Act, fail, and settle. Accept or Reject starts as an action. Its small open-ring witness moves while the event travels. A refused send leaves a diamond on Retry and Cancel. Success briefly announces Accepted or Rejected; the changed content and square-marked Undo Button remain. Sent remains as a status until an agent picks the decision up.

Edit and hand off. Opening the draft above replaces Edit with dot-marked Save and Cancel Buttons; Save uses the moving ring while it sends. The saved draft arrives with a Waiting for pickup status. When an agent claims that unsettled edit, the same target gains an animated Active disclosure.
