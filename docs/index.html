The conversation stays with the work.

A comment belongs to the passage it asks about. A choice or a moved card reaches the agent where it is working. Its next revision arrives in the same page, with your decisions and reading position preserved.

Pages for real work.

  • Review a proposal Compare approaches and discuss the tradeoffs in place.
  • Follow a release Keep the current state beside the evidence and next action.
  • Review code Move from the explanation into the exact change.

When a task needs a new widget, your agent can build it and reuse it in later pages. Explore the full gallery or see how packages extend Leaf.

Bring Leaf to your agent.

You need uv, jq 1.6 or newer, and a browser on the same machine.

Claude Code

/plugin marketplace add max-sixty/leaf
/plugin install leaf@leaf

Codex

codex plugin marketplace add max-sixty/leaf
codex plugin add leaf@leaf

Then ask: “Use Leaf to write up the options for this change.” You can also invoke /leaf in Claude Code or $leaf in Codex.
