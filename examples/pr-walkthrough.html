Unified diff in the switch picker

Worktrunk PR #3865 makes unified diff the switch picker’s default, centralizes Git diff preparation, and demand-loads off-screen worktrees. The exact 46-file patch and review history are included below.

Agent brief

This large change has a small architectural spine. PreparedDiff owns one complete Git diff invocation, while TempIndex admits untracked files without changing the user’s real index. The picker then decides which rows to warm immediately and which worktree previews to load only when selected.

Review identified sparse-checkout divergence, a predictable shared temporary directory, a symlink race while copying the index, and stale prewarming claims; all four were corrected before merge. Two follow-ups remain: selected-row demand latency has no benchmark, and wt step commit --dry-run can still stage its own temporary-index artifact when TMPDIR sits inside the worktree.

Change surface

Risk is concentrated in the Git repository layer and picker runtime. Tests, documentation, and benchmarks account for most of the remaining files.

Review invariants

The implementation is expected to preserve these three properties. 

assert_eq!(real_index_after, real_index_before);
assert!(temp_index.is_operation_scoped());
assert!(offscreen_worktree_preview.is_demand_loaded());
A clean status is insufficient: preview preparation must preserve the real index byte for byte. Random, exclusive temporary files prevent concurrent previews from sharing or replacing one another’s index. Moving off-screen worktrees out of prewarm protects startup, but leaves selected-row latency as a separate measurement question.
