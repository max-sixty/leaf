# Packages

`../references/packages.md` and the `package-*.md` files beside it own the package
contract; `../references/module-authoring.md` and the `module-*.md` files own what a
behavior module must do and the public browser API. `../assets/AGENTS.md` holds the
browser-wide rules a module must keep and maps each concern to its runtime module.
`build/AGENTS.md`, “Committed bundles”, rebuilds vendor bundles and stylesheets: where
a bundled package has `styles/` sources, edit those, not its generated sheets.
