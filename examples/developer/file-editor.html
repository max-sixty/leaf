Edit the file

Changes save automatically. The editor follows changes made elsewhere and asks which version to keep when edits overlap.

Where the file lives

The page binds files/research-notes.md in its own directory, so every copy of the page, a preview or a visitor's on leaf.page, edits its own copy: 

leaf file bind "$PAGE" research-notes "$PAGE/files/research-notes.md"

Edit a line and inspect the file on disk. A normal save leaves the header still. Hold a write request open to inspect delayed saving feedback. Change a line you are not editing during an unsaved edit and the editor takes it in; change the line you are editing to inspect conflict recovery. With the binding withdrawn (leaf file unbind), the editor explains what is missing.
