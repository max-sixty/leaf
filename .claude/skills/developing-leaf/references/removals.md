# Measure a removal

Measure a removal or consolidation that root `AGENTS.md`'s "Regular maintenance"
finds by making the change in a scratch worktree: `git diff --numstat` gives what it
deletes, and a probe or capture of the affected journey shows what users lose. A count
read off the code overstates the saving.

`uv run leaf-dev logs usage` counts what the pages on this machine used: each widget,
package, command and `leaf` command. It records the people and agents who worked here,
so a feature nothing used is a candidate to test, as by giving it a place in a catalog
example, and the count alone decides no removal.
