# Packages

contract, and `../references/module-authoring.md` and the `module-*.md` files what a
behavior module must do and the public browser API. `../assets/AGENTS.md` holds the
browser-wide rules a module must keep. Where a bundled package has `styles/` sources,
edit those rather than its generated sheets, and rebuild as `build/AGENTS.md` says.
